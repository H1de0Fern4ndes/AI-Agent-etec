# Stack tecnológica

- **TypeScript** como linguagem principal, atendendo à preferência por uma stack popular e confiável.
- **React** para construir a interface do site institucional e do catálogo.
- **Vite** para desenvolvimento local e geração da versão de produção.
- **CSS responsivo** para oferecer uma experiência adequada em dispositivos móveis e navegadores modernos.
- **Dados locais/mock** para cursos, matrizes curriculares e disciplinas enquanto a fonte definitiva não estiver integrada ou confirmada.

Manter a arquitetura simples e adequada a um site institucional. A escolha de uma solução de backend ou de persistência fica para quando houver requisitos que a justifiquem.
