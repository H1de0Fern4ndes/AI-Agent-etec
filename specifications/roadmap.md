# Roadmap

## Fase 1 - Fundação
- Definir identidade visual.
- Estruturar páginas institucionais.
- Implementar layout responsivo.

## Fase 2 - Catálogo acadêmico
- Catalogar cursos técnicos.
- Importar matrizes curriculares.
- Descrever disciplinas e objetivos.

## Fase 3 - Gestão de conteúdo
- Configurar banco SQLite.
- Criar API de notícias.
- Implementar login administrativo.

## Fase 4 - Publicação e validação
- Cadastrar notícias.
- Exibir notícias na página inicial.
- Validar navegadores, acessibilidade e mobile.
